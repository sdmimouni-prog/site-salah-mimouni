# Platform pictograms

Original glyphs from the open Simple Icons catalogue (CC0). These indicate platforms only, not verified podcast presences. URLs must be supplied separately in src/content/podcasts.ts.

- Spotify, Apple Podcasts, YouTube, Deezer: https://github.com/simple-icons/simple-icons/tree/develop/icons — retrieved 27 September 2026.
- Amazon Music: https://github.com/simple-icons/simple-icons/blob/13.21.0/icons/amazonmusic.svg

No logo paths were redrawn. CSS displays the existing glyphs in white on a colored background.
